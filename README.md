# Tarangini Sarvagyam: portfolio

A static, accessibility-first portfolio. No build step: open `index.html`, or serve the folder with any static host (GitHub Pages, Netlify, Cloudflare Pages).

- `index.html`: the one-page portfolio
- `experience.html`: the Archive, every role by year
- `case-woods-at-sasan.html`: the Woods at Sasan case study
- `assets/`: images, video and PDFs
